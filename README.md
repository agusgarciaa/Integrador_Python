## Trabajo Integrador 2026
Este proyecto corresponde al Trabajo Integrador de la materia Seminario de Lenguajes, utilizando Python como lenguaje principal.

## Descripción:
Desarrollo de una aplicación en Python para analizar y visualizar datos de biodiversidad (Darwin Core), incluyendo limpieza de datos e interfaz gráfica con Streamlit.

## Tecnologías:
- Python
- Streamlit


## Guía de Configuración del Proyecto:
#### 1. Requisitos previos: 
Verificá tener instalada la versión Python 3.13.9. Podés comprobarlo abriendo tu terminal y ejecutando el siguiente comando:

        python --version

#### 2. Crear el entorno virtual (VENV)
Para mantener las librerías del proyecto aisladas y no interferir con tu sistema, es recomendable crear un entorno virtual. Ubicate en la carpeta principal del proyecto y ejecutá:

        python -m venv .venv

#### 3. Activar el entorno
Para comenzar a usar el entorno, debés activarlo. Según tu sistema operativo, utilizá el comando correspondiente:

        Windows: .venv\Scripts\activate

        Mac/Linux: source .venv/bin/activate


Nota: Sabrás que el entorno está activo porque verás el prefijo (.venv) al inicio de la línea en tu terminal.

#### 4. Instalar las dependencias
Con el entorno activado, procedé a instalar Streamlit y las demás librerías necesarias para que el proyecto funcione:


        pip install -r requirements.txt


#### 5. Cómo ejecutar la aplicación
Dado que la interfaz gráfica está desarrollada con Streamlit, el proyecto se inicia con un comando específico en lugar del habitual de Python. Ejecutá:


        streamlit run archivo.py
